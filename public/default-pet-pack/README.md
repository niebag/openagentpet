# Default Pet pack artwork

The five GIFs in this directory were generated for OpenAgentPet on 5 August
2026 from an original robot illustration created with OpenAI's image-generation
tool. The repository owner then cropped and animated the five Activity states.
They do not reuse the previous Clawd artwork.
